# Content guide — changing the site without code

Everything below is done in the dashboard (`/admin`). Changes appear on the public site immediately.

| I want to… | Go to |
|---|---|
| Change any wording (titles, paragraphs, button labels, menu labels, footer text, programs, stories, FAQ, testimonials, news), in English and French | **Texts** |
| Add, reorder, duplicate or remove an item of a list (story, FAQ, testimonial, news…) | **Texts** → open the list |
| Create a new page (e.g. a program, "Livelihood week"), edit it with blocks, preview, publish, unpublish | **Pages** |
| Change where a button leads, hide it, open it in a new tab | **Buttons & links** |
| Change the main menu (order, visibility, destinations) or hide/reorder home page sections | **Menu & home page** |
| Enter the impact figures shown on the home page | **Menu & home page** → Impact figures |
| Show, hide, reorder programs; choose their cover picture | **Programs** |
| Add or remove gallery photos and videos | **Gallery** |
| Upload, replace or delete pictures | **Media library** |
| Change the logo (colour, white, black), partner logos, testimonial photos, banner photos | **Logo & partners** |
| Change phone, email, address, map, social links, footer blocks | **Contact & social** |
| Read contact messages and newsletter sign-ups | **Messages** |
| Add team members / reset a password | **Users** (administrators only) |

## Good to know

* **Two languages.** Texts are written in both languages side by side. A page created in **Pages** is shown in a language only when it is complete in that language; the editor lists what is missing.
* **Nothing invented.** The impact-figures section stays hidden until you enter real numbers. Partner entries named "Partner One…" are never shown.
* **Pictures.** A missing picture is replaced by a branded colour block. Use descriptive text ("alt text") for every image.
* **Buttons.** The *words* of a button are in **Texts**; its *destination* is in **Buttons & links**. Menu items are in **Menu & home page**.
* **Not editable from the dashboard (by design):** the structure of existing pages (their layout), the browser-tab icon (favicon), the code-level routes (`/about`, `/programs`, …), and the *destination* of the "Back to…" links.
* **Order of things on a page** is fixed for existing pages; the home page sections and the blocks of custom pages can be reordered.
